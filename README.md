# 2026 Midterm Election Forecast

A probabilistic forecast of the 2026 US House and Senate elections (Election Day:
November 3, 2026), with a live election-night dashboard on
[matthewburns.net](https://www.matthewburns.net/).

Work in progress. See `CLAUDE.md` for scope and decisions.

## Development

```bash
uv sync
uv run pytest
uv run ruff check
```
